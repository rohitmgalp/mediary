☁️ Multi-device cloud sync

Connects this app to a free cloud database (Firebase) so the same data shows up on your phone and your computer. This only works once the app is hosted on your own Netlify/GitHub Pages link — it's switched off automatically inside this claude.ai preview, since that sandbox blocks outside network calls.
⚠ Cloud sync can't run inside the claude.ai preview. Deploy this file to Netlify or GitHub Pages first, then open it from that URL to use this tab.

1. One-time Firebase setup (free, ~5 minutes)

Do this once. It gives you a free cloud database you own — Google's free tier is generous enough for this app forever.
  1. Go to console.firebase.google.com → Add project → give it any name → skip Google Analytics → Create.
  2. In the left menu: Build → Firestore Database → Create database → choose any location → Start in test mode.
  3. In the left menu: Project settings (gear icon) → General → scroll to "Your apps" → click the </> (web) icon → register an app (any nickname) → skip hosting.
  4. Copy the apiKey and projectId values shown in the config box into the two fields below.

2. Connect this device

On your first device, click "Generate new code" and save it. On every other device, type that same code in here instead of generating a new one — that's what links them together.

3. Keeping devices in sync

Once connected, every change you make here uploads automatically a couple of seconds later, and the app checks for updates from your other devices when you open or return to this tab.
This is convenience-level privacy, not bank-grade security: anyone who has your exact sync code, project ID and API key could read or edit this data (which includes customer names/phone numbers). Don't share the sync code, and don't reuse a password you use elsewhere as the code.
